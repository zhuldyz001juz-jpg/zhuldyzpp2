# Practice 6: Python File Handling and Built-in Functions

## Objective

The objective of this practice is to learn how to work with files, directories, and built-in Python functions.

## Topics Covered

### 1. File Handling
- Reading files using `read()`, `readline()`, and `readlines()`
- Writing and appending text
- Using the `with` statement
- Copying and deleting files
- Counting lines in a file

### 2. Directory Management
- Creating directories
- Listing files and folders
- Finding files by extension
- Checking path permissions
- Moving and copying files
- Creating 26 text files from A.txt to Z.txt

### 3. Built-in Functions
- `len()`, `sum()`, `min()`, and `max()`
- `map()`, `filter()`, and `reduce()`
- `enumerate()` and `zip()`
- `sorted()` and type conversions

Open the project in VS Code or PyCharm.

Run each Python file separately:

